# 쇼츠 제작 워크플로 — [고대유물의 비밀]

대본 한 편에서 업로드까지 7단계. **워크플로는 고정이고, 카테고리는 설정 파일
하나로 바꾼다.** 다른 PC에서 이 저장소를 받아 `채널설정.json` 만 갈아끼우면
같은 파이프라인이 다른 채널로 돈다.

현재 채널은 고대 유적·유물의 발견부터 출토품, 역사적 배경, 공간 관계, 문헌과
과학 조사, 아직 남은 미지까지 추적하는 **고증형 역사 미스터리 다큐**다. 단면·치수·
분해도는 유물을 이해하는 데 필요할 때 쓰는 시각 언어이지, 모든 이야기의 결론이 아니다.

## 카테고리를 바꾸려면

**`채널설정.json` 하나만 고친다. `tools/` 안의 코드는 건드리지 않는다.**

| 항목 | 무엇을 바꾸나 |
|---|---|
| `채널` | 이름, 슬러그, 주제 목록 파일 경로 |
| `tts` | 보이스 ID, speed / stability / similarity / style |
| `자막` | 글꼴, 크기, 획 두께, 세로 위치 |
| `워터마크` | 위치, 크기, 크로마키 색 |
| `시각화` | 증거 상태, 장면 길이, 이미지 문자 금지, 연속성 규칙 |
| `썸네일` | 상단 문구, 글꼴, 제목 색 |
| `업로드` | 유튜브 카테고리 ID, 언어, 해시태그 상한 |
| `캡컷` | 템플릿 프로젝트 이름 |

지침 문서(01~07)도 카테고리에 맞게 손본다. 파이프라인 구조는 유지하되
**조사 항목, 질문 구조, 증거 상태, 장면 유형**을 주제에 맞게 바꾼다. 특히:

- **01 / 01L 대본 지침** — 조사 잠금, 질문 장부, 증거의 경계
- **02 시각화 지침** — 의미 단위 장면 분할, 행동 기반 카메라, 증거 상태
- **06 썸네일** — 배경 프롬프트의 `{{ }}` 자리만 교체

## 7단계 전체 흐름

### 2트랙 — 숏폼 / 롱폼

주제마다 어느 쪽으로 갈지 먼저 정한다. 발견 단계, 출토품 군, 공간 여정, 증거 충돌,
보존 문제, 미해결 질문 가운데 **세 가지 이상**이 충분한 자료를 가지면 롱폼으로 보낸다.
판단 기준은 [01L §2](./01L.롱폼_대본작성지침.md)를 따른다.

| 길이 | 2~3분 | 8~13분 (표준 11분) |
| 대본 | 1,100~1,400자 | 자료 밀도에 따라 8~12분 |

| 질문 | 질문→증거→해석→더 큰 질문 | Q0 중심 질문 + 질문 장부 |
| 결말 | 확인/의미/미지/이유 회수 | 확인/의미/미지/다음 증거 회수 |
| 지침 | [01](./%23%20%5B고대유물의%20비밀%5D%20대본%20작성%20전용%20시스템%20지침.txt) | [01L](./01L.롱폼_대본작성지침.md) |

## 이 채널의 정체성 — 증거에서 미지로

모든 영상은 다음 흐름을 가진다.

```
구체적인 발견 행동
→ 실제 출토품과 발굴 맥락
→ 유물이 증언하는 시대와 문명
→ 외곽·중심·지하의 공간 반전
→ 발굴·측정·문헌·해석의 경계
→ 아직 모르는 것과 모르는 이유
```

- 한 장면에는 이미지 프롬프트 1개와 영상 프롬프트 1개만 둔다.
- 같은 시간·장소·대상·연속 행동인 2~3문장은 한 장면이 될 수 있다.
- 행동, 장소, 증거 상태, 시각 표현이 바뀌면 새 장면이다.
- 생성 길이는 실제 TTS를 기준으로 4·6·8·10초 중 가장 짧은 값을 고른다.
- 카메라는 발견 행동이나 공간 관계를 따라가며, 정보 확인에 필요하면 멈춰도 된다.
- 치수선·지도선·증거 배지는 이미지에 생성하지 않고 Remotion에서 넣는다.

세로(9:16)는 우물에서 지층으로, 지상에서 무덤 중심으로 내려가는 공간 여정을
강하게 보여 줄 수 있다. 자세한 규칙은 [02](./02.시각화+영상화프롬프트(고대유물).txt)를 따른다.

## 규칙

1. **크레딧·계정을 쓰는 명령은 기본이 드라이런.** `--run` 없이는 아무 일도 안 난다.
2. **키는 `.env` 에만.** 지침이나 코드에 절대 적지 않는다. 원격에 한 번이라도
   올라가면 히스토리에서 지워도 유출로 보고 재발급한다.
3. **동양 유물에 서양 그림이 나오면 채널이 죽는다.** 회차마다
   `02b.고증카드.md` 를 프롬프트보다 먼저 쓰고, `prompt_check.py` 를
   통과해야 FLOW 에 넣는다.
4. **출처를 댈 수 없는 내용은 대본에 넣지 않는다.** 회차마다 `00.팩트체크.md` 를
   쓰고, C등급(문헌만·실물 미확인)이 있으면 설명란에 재현 고지를 넣는다.
   업로더가 이걸 검사해서 없으면 막는다.
5. **내보내기 전에 `verify_draft.py` 를 돌린다.** 영상·나레이션·자막이 같은
   시간축에 놓였는지, 소리가 클리핑하지 않는지 41개 항목을 전수 검사한다.
   실패가 하나라도 있으면 올리지 않는다.
6. **새로 걸린 함정은 [00.함정목록.md](./00.함정목록.md) 에 한 줄 추가하고,
   반드시 코드나 지침에도 박는다.** 표에만 적으면 다음에 또 걸린다.
