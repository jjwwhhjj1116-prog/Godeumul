# [고대유물의 비밀] 쇼츠 제작 워크플로

고대 유적·유물의 **숨겨진 공학 메커니즘**을 3D 디오라마 단면으로 해부하는
세로 쇼츠 채널. 신비한 건축사전의 시각 문법(줌인 → 단면 → 분해 → 원리)을
고고공학 주제에 이식한 것이다.

---

## 7단계 전체 흐름

| 단계 | 하는 일 | 입력 | 출력 | 문서 |
|---|---|---|---|---|
| **1** | 대본 작성 | 유물 주제 1개 | 5챕터 나레이션 대본 | [01](./%23%20%5B고대유물의%20비밀%5D%20대본%20작성%20전용%20시스템%20지침.txt) |
| **2a** | 장면 구분표 | 대본 | 컷 배분 + 해부 쿼터 검증 | [02](./02.시각화+영상화프롬프트(고대유물).txt) |
| **3** | **TTS 실측 (먼저!)** | 장면 구분 | `audio/*.mp3` + `durations.json` | [03](./03.TTS생성지침.md) |
| **2b** | 프롬프트 생성 | 실측 길이 | 컷별 6대 항목 + 옴니 규격 | [02](./02.시각화+영상화프롬프트(고대유물).txt) |
| **4** | 이미지·영상 생성 | 프롬프트 txt | `images/` `clips/` | [04](./04.FLOW+옴니_생성지침.md) |
| **5** | 캡컷 편집 | 위 전부 | `*_final.mp4` | [05](./05.캡컷_편집지침.md) |
| **6** | 제목·설명·썸네일 | 완성 영상 | 메타 + 썸네일 | [06](./06.제목_설명_썸네일지침.md) |
| **7** | 업로드 | 전부 | 공개 쇼츠 | [07](./07.업로드지침.md) |

각 단계는 **파일로만 연결된다.** 앞 단계 산출물이 없으면 다음 단계가 못 돈다.

> ★ **2단계는 TTS를 사이에 두고 둘로 갈라진다.** 옴니 영상 길이를 4/6/8/10초
> 규격에서 골라야 하는데, 그러려면 나레이션 실측 길이를 먼저 알아야 한다.
> 추정치로 정하면 영상을 전부 다시 뽑게 된다.

## 이 채널의 정체성 — 줌인 해부 체인

전부 여기서 나온다. 다른 규칙은 다 이걸 지키기 위한 장치다.

```
L1 EXTERIOR   지상 전경. 유물의 겉모습
L2 APPROACH   접근. 표면 질감이 보이는 거리
L3 CUTAWAY  ★ 지표를 잘라 내부 노출. 절단면에 지층이 보인다
L4 EXPLODED ★ 부품이 공중에서 분해되어 떠 있다
L5 MECHANISM★ 부품 하나에 초근접. 힘이 붉은 화살표로 흐른다
```

- **챕터 4(역발상 솔루션)는 L3 → L4 → L5를 전부 밟아야 한다.**
- 겉모습 컷이 연속 3개를 넘으면 위반이다.
- 이 채널이 다루는 대상은 대부분 땅속·물속에 있어 실사로 찍을 수 없다.
  단면과 분해가 유일한 답이고, 그게 시청자가 여기 오는 이유다.

세로(9:16)는 불리한 조건이 아니라 유리한 조건이다. 무덤 수직갱, 우물, 지하
궁전, 피라미드 내부 통로 — 고대유물 주제는 수직 구조가 많다.

## 자주 쓰는 명령

```bash
python tools/tts_generate.py "산출물/EP01_진시황릉/02.시각화.txt"
```
```bash
python tools/tts_generate.py "산출물/EP01_진시황릉/02.시각화.txt" --run
```
```bash
python tools/speed_table.py "산출물/EP01_진시황릉"
```
```bash
python tools/subtitle_split.py "산출물/EP01_진시황릉/01.대본.txt" --srt
```
```bash
python tools/capcut_build.py "산출물/EP01_진시황릉" --check
```

`tts_generate.py`는 **기본이 드라이런**이다. `--run` 없이는 크레딧을 쓰지 않는다.
텍스트가 안 바뀐 장면은 자동으로 건너뛰므로 재실행해도 안전하다.

## 다른 파이프라인과의 관계

- **무협 TTS 파이프라인** (`../TTS+영상 변환기/`)과 같은 ElevenLabs 계정을 쓴다.
  월 한도를 공유하므로 대량 생성 전에 잔여량을 확인할 것.
- 이 채널은 무협 파이프라인 코드를 **건드리지 않는다.** 완전히 별도 폴더,
  별도 스크립트다. 무협 회귀 테스트에 영향이 없다.
- 02단계 지침은 무협 `03E.시각화+영상화프롬프트(무협).txt` v11.1을 이 채널용으로
  개작한 것이다. 워크플로 골격(컷 판정 → 해부 → 프롬프트 → I2V)은 동일하다.

## 보안

`.env`에 ElevenLabs 키가 들어 있고 `.gitignore`로 제외되어 있다.

- **원격 저장소에 올리기 전에 반드시 `git status`로 `.env`가 빠졌는지 확인한다.**
- 채널 폴더의 `API key (보안중요).txt` 류 파일도 `.gitignore`가 걸러내지만,
  파일명이 다르면 안 걸린다. 커밋 전 목록을 눈으로 볼 것.
- 키가 한 번이라도 원격에 올라가면 히스토리에서 지워도 유출로 간주하고
  ElevenLabs 대시보드에서 재발급해야 한다.
