# 고대유물 제작 총괄

## 2026-09-11 우선 변경

시각화 단계에서는 저장소 루트 `02D.역사3D디오라마_현행기준.md`를 먼저 읽는다. EP13부터 실물 형태를 잠근 유물과 역사 3D 디오라마 배경이 기본이다. 아래 실사 기본·확장 runner 기본은 이 지시로 대체한다. Flow는 Chrome 본문 직접 첨부·생성, TXT는 사용자 수동 입력용으로도 제공한다. 기존 대본·TTS와 검수 게이트는 유지한다.

2026-09-10 사용자 요청. 이 스킬의 신규 회차 정책은 이전 문서의 상충하는 기본값보다 우선한다. 다른 채널에는 적용하지 않는다.

## 승인과 재개

- 2026-09-10 최신 CapCut 지시: 줌 1 애니메이션만 사용하고 장면 전환 효과는 전부 사용하지 않는다. 아래 표와 과거 문서의 왼쪽으로 밀기 지시보다 우선한다. 신규 회차의 전환 수는 0이어야 한다. 애니메이션 지속시간은 여전히 컷 전체와 일치해야 하며 짧으면 없음→줌1로 초기화한다. 이전 게시 영상은 이 지시만으로 수정하지 않는다.

- 2026-09-10 사용자 명시 승인 정책: 이 채널에서 대본을 승인하고 영상 제작을 지시하면 해당 승인 대본을 기존 ElevenLabs API로 전송하는 유료 TTS와 기존 Flow 크레딧을 사용하는 정상 제작을 포함한다. 동일 대본·동일 서비스·동일 제작 범위에 대해 유료라는 이유만으로 재승인을 반복하지 않는다. 실제 실행 권한 심사를 생략하거나 거부를 우회하라는 뜻은 아니다. 거부 시 기존 승인 문구와 정확한 payload/서비스를 근거로 제시한다.

- 사용자가 준 제미나이 대본은 사실 오류와 잘못된 단정만 최소 수정한다. 말맛, 체감 과장, 근거 있는 가설, 열린 질문은 보존한다. 시청자 투표를 역사적 증명의 대체물로 삼지 않는다.
- 작성 완료와 사용자 승인을 구분한다. 현재 대본 해시와 승인 발화를 기록한다. 승인 뒤 이미 허용된 TTS/Flow 비용 범위에서 납품까지 계속하며 매 단계 같은 승인을 다시 묻지 않는다.
- 대본 승인만으로 새로운 유료 서비스, 무제한 재생성, 공개 게시를 허용하지 않는다. 승인 범위 밖 비용, 인증, 의미 변경만 사용자에게 요청한다. 게시 승인이 없으면 업로드 직전까지 진행한다.
- 매 재개 때 회차 상태와 산출물 해시를 확인한다. 실패/접수 불명 작업은 재전송 전에 원격 결과부터 확인한다. 반복 동일 연결 시험은 최대 두 번. 브라우저 장애는 최초 도구/시각/원문/마지막 성공을 남긴다.
- 단계 에이전트는 아래 역할 계약을 따르는 작업 단위다. 여러 에이전트를 실제 실행할 수 없는 환경에서는 총괄이 순서대로 수행한다. 문서 존재를 실행 중인 자동화로 보고하지 않는다.

## 신규 영상 기본값과 충돌 해결

- 전 컷 I2V. 실사형 고고학 재현을 기본으로 하며 새 스타일은 사용자 명시 지시가 있을 때만 변경한다. 오래된 HYBRID/T2V/마네킹/미니어처 강제 설정을 그대로 실행하지 말고 회차 설정에 이 선택을 명시한다.
- TTS가 타임라인의 소유자다. 28개×8초는 소스 길이이지 완성 길이가 아니다. 실제 허용 생성 길이와 컷별 편집 길이를 따로 기록하고 배속=소스길이/편집길이로 계산한다. 과도한 배속으로 의미가 사라지면 장면 계획을 재검토한다.
- 시작/끝 이미지는 같은 공간에서 이동 가능한 두 상태일 때만 짝짓는다. 번호가 연속이라는 이유만으로 001→002를 강제하지 않는다.
- 이미지·영상 txt는 각각 장면당 영문 한 문단, 장면 사이 빈 줄 하나. 이미지 번호와 프롬프트 수, 실제 참조 첨부를 대조한다. 기존 Flow extension runner를 사용한다.

## 카메라·설명 동작 검수

02M.대본연동_설명영상_필수검문.md를 읽고 아래를 추가한다.
- 모든 컷에 대본 구절, 관찰할 실물 부위, 카메라 시작 위치→동선→도착 구도, 시간대별 속도, 대상의 실제 동작, 끝 상태를 적는다. cinematic/dynamic/slow zoom만으로 제출하지 않는다.
- 발견은 손과 도구를 따라 이동, 공간은 전경을 지나는 전진 이동, 문양은 전체→해당 부위로 접근, 비교는 두 자료의 대응 부위 강조처럼 정보 목적에 맞춘다. 같은 느린 줌의 반복은 사유 없으면 반려한다.
- 평면 회화는 크게 회전해 보이지 않는 뒷면을 발명하지 않는다. 뿔 논쟁을 강조한다고 실제 붓선을 뿔로 변형하지 않는다. 형태 잠금은 카메라/손/설명선까지 정지하라는 뜻이 아니다.
- 수치는 검증된 값만 사용한다. 설명선의 생성/진행/완료를 음성 구간에 맞춘다. 가짜 분석 그래프와 무관한 치수선 금지.
- 생성 후 전체 재생과 시작/중간/끝을 확인해 실제 이동·설명 동작·형태·문장 일치를 기록한다. 파일만 있으면 완료가 아니다. 움직임 없으면 MOTION_MISSING. 체크리스트만으로 실제 영상 검수를 대신하지 않는다.

## 승인된 제작을 멈추지 않는 보고

상태는 NOT_STARTED / RUNNING / VERIFIED / BLOCKED로 구분한다. VERIFIED에는 실제 산출물·검수 근거가 있어야 한다. 승인 후 정상 단계 사이에는 질문 대신 진행한다. 중단 시 완료 범위, 정확한 오류, 안전한 다음 행동만 알린다. 예약 시각이 지났다면 임의 공개하지 않는다.
