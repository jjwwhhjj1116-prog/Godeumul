# EP01 진시황릉 — 팩트체크

주제 100선 **21번: 진시황릉의 수은 강과 자동 석궁**

대본 지침 §3(안티할루시네이션)과 07단계 업로드 게이트("출처를 댈 수 있는 내용만")
에 따라, 대본의 각 주장이 어디에 근거하는지 등급을 매겨 둔다.

| 등급 | 뜻 |
|---|---|
| **A** | 발굴·실측으로 물리적으로 확인됨 |
| **B** | 문헌 기록 + 관련 출토 유물로 원리 재구성 가능 |
| **C** | 문헌 기록만 있음. 실물 미확인 |

## ★ 반드시 처리할 것 — 지궁 미발굴 고지

대본의 **페이오프인 자동 석궁은 C등급**이다. 진시황릉 지궁은 아직 발굴되지
않았고, 석궁 함정망은 사기 기록에만 나온다. 대본은 이걸 **실제로 확인된 장치처럼**
서술하고 있다.

그대로 올리면 지침 §3 위반이다. 아래 중 하나를 반드시 적용한다.

**① 설명란 고지 (기본 · 권장)**
```
※ 진시황릉 지궁은 현재까지 발굴되지 않았습니다.
   본 영상의 석궁 장치는 사기(史記) 기록과 병마용갱에서 출토된
   진나라 청동 노기 실물을 근거로 재구성한 것입니다.
   수은은 봉토 토양의 수은 이상치로 실측 확인되었습니다.
```

**② 화면 라벨 (병행 권장)**
석궁 메커니즘 컷(Ch4)의 우상단에 작게 `RECONSTRUCTION` 라벨.
02단계 지침의 [라벨 규칙]대로 영문·1개.

**③ 대본 삽입 (톤을 해칠 수 있어 비권장)**
Ch4 앞에 한 문장: `아직 아무도 열어보지 못한 공간이거든요.`
→ 오히려 후킹이 강해지는 효과는 있다. 넣을지는 판단이 필요하다.

## 참고 출처 (설명란용)

- 사기(史記) 권6 진시황본기 — 수은 강·바다, 기노시 기록
- 진시황릉 봉토 토양 수은 함량 조사 (1980년대 초 최초 보고, 2000년대 재조사)
- 진시황릉 병마용갱 출토 청동 노기 — 진나라 석궁 방아쇠 3부품 구조
- 진시황제릉박물원(秦始皇帝陵博物院) 공개 자료

> 업로드 전에 위 출처의 **구체적 수치와 연도를 한 번 더 확인**할 것.
> 특히 토양 수은 조사의 측정값과 노기 장력 추정치.

## 지침 레퍼런스와의 중복 회피

대본 작성 지침 §6의 모범 레퍼런스 대본이 이미 진시황릉이다
(수은 + **천장 모래 트랩**).

이 회차는 페이오프를 **자동 석궁 방아쇠 메커니즘**으로 잡아 겹치지 않게 했다.
모래 트랩은 이번 대본에 넣지 않는다. 나중에 별도 회차로 쓸 수 있다.
