# EP01 진시황릉 — 구버전 팩트체크(불합격·재조사 필요)

구버전 주제: **진시황릉의 수은 강과 자동 석궁**

> 이 문서는 v2 대본이 왜 배포 불가인지 남기는 감사 기록이다. 새 EP01의 조사노트로
> 사용하지 않는다. `자동 석궁`을 결론으로 먼저 정한 뒤 자료를 끼워 맞췄고, 문헌과
> 측정을 합쳐 `발굴확인`처럼 취급한 것이 핵심 결함이다.

대본 지침 §3(안티할루시네이션)과 07단계 업로드 게이트("출처를 댈 수 있는 내용만")
에 따라, 대본의 각 주장이 어디에 근거하는지 등급을 매겨 둔다.

| 상태 | 뜻 |
|---|---|
| **발굴확인** | 공식 발굴 맥락과 실물로 확인됨 |
| **측정확인** | 과학 조사로 성분·범위·연대 등을 확인함 |
| **문헌기록** | 기록에는 있으나 실물 확인과 별개임 |
| **학술해석** | 증거를 바탕으로 한 전문가 해석임 |
| **미확인** | 직접 증거가 없거나 전설·추측 단계임 |

## ★ 판정 — 설명란 고지로 해결할 수 없음

대본의 페이오프인 자동 석궁은 `문헌기록`이며 중앙 지궁의 장치 실물은 확인되지
않았다. 병마용갱의 청동 노기는 진나라 석궁 기술의 실재를 보여주지만, 이것이 중앙
지궁에 설치된 함정의 구조를 증명하지는 않는다.

따라서 설명란 고지나 작은 `RECONSTRUCTION` 라벨만 붙여 기존 각도를 살리는 방식은
불충분하다. 자동 석궁은 문헌이 전하는 여러 주장 중 하나로만 제한하고, 새 대본의
중심은 실제 출토품 군과 능원 전체의 공간 관계, 중앙부를 발굴하지 않는 이유로 바꾼다.

## 지침 레퍼런스 오염 기록

구버전 지침의 진시황릉 모범 대본이 수은·모래 함정을 확정적 해법처럼 제시했고,
이를 피하려다 자동 석궁을 새 페이오프로 선택했다. v3 지침에서는 특정 주제의 모범
결론을 제거했다. 이후에는 중복 회피가 아니라 조사 결과로 중심 질문을 선택한다.
