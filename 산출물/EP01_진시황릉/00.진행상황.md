## ★ 막힌 것 — 크롬 다운로드 차단 (30초면 해결)

Flow에서 생성한 이미지를 내려받으려는데, **크롬이 이 사이트의 연속 다운로드를
차단**했습니다. 첫 1장만 받아지고 나머지가 전부 막혔습니다.

주소창 오른쪽에 다운로드 차단 아이콘(⊘ 또는 ⬇)이 떠 있을 겁니다. 거기서
**"labs.google에서 여러 파일 다운로드 허용"**을 눌러주세요.

안 보이면:
```
크롬 설정 → 개인정보 및 보안 → 사이트 설정 → 추가 콘텐츠 설정
→ 자동 다운로드 → "허용" 에 labs.google 추가
```

**주의:** Flow 다운로드는 `내 Chrome`이 아니라 **Profile 18**로 떨어집니다.
현재 저장 경로가 `OneDrive\바탕 화면\유투브\셀팜\그록영상(15)` 로 되어 있어요.
이 채널 작업용으로 바꾸시려면 그 프로필의 다운로드 폴더를 조정하셔야 합니다.

## 영상 생성을 왜 2개에서 멈췄나

**무인 상태에서 계속하면 크레딧을 낭비할 위험이 컸습니다.**

Flow 그리드에서 이미지를 골라 "애니메이션 적용"하는 방식으로 돌렸는데,
영상이 하나 완성될 때마다 **이미지 필터가 풀리면서 타일 위치가 밀립니다.**
실제로 3번째 시도에서 컷24 프롬프트에 컷25 이미지가 붙는 사고가 났고,
바로 취소했습니다.

무인으로 24개를 더 돌리면 이런 불일치가 몇 개나 섞일지 알 수 없고,
컷당 12크레딧이라 되돌리려면 다시 그만큼 듭니다.
게다가 **어차피 다운로드가 막혀 있어 오늘 밤에 조립까지는 못 갑니다.**

그래서 멈추고, 위치에 의존하지 않는 안전한 절차를 정리해 뒀습니다(아래).

## 깨어나신 뒤 순서

### 1) 다운로드 허용 (위 참조)

### 2) 이미지 25장 내려받기
Flow 프로젝트에서 `02c.이미지선택.md`의 채택본을 받으시면 됩니다.
제가 이어서 하는 게 빠르면 말씀만 주세요 — 브라우저로 순차 처리하겠습니다.
받은 파일은 `images/001.jpg` ~ `025.jpg` (장면번호 3자리)로 정리합니다.

### 3) 영상 25컷 생성 — 안전 절차
그리드 대신 **프롬프트 바의 "시작" 버튼 → 에셋 선택기**를 씁니다.
이 목록은 이미지만 보여주고 영상이 늘어도 순서가 안 변합니다.

```
시작 클릭 → 목록에서 해당 이미지 클릭 → "프롬프트에 추가"
→ 설정에서 길이 지정(4/6/8/10초) → 영상 프롬프트 붙여넣기 → 생성
```

컷별 길이와 프롬프트는 `02.시각화.txt`에 전부 있습니다.
예상 크레딧: **약 260** (x1 기준, 잔여 1900).

### 4) 캡컷
영상이 모이면 `05.캡컷_편집지침.md`대로 진행합니다.
배속은 `tools/speed_table.py`가 계산해 줍니다(전 컷 1.12~1.56x로 이미 확인됨).
자막은 `자막.json`(110개, 최대 16자)을 쓰면 됩니다.
