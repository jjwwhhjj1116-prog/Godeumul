## 구버전 배포 차단 — 보존 기록

구버전 대본·25장면·영상·최종 렌더는 폐기된 v2 지침의 `공학 해법→자동 쇠뇌` 각도를
기준으로 만들었다. `문헌기록`과 `발굴확인`의 경계가 흐리고, 진시황릉의 실제 출토품과
능원 전체의 공간 서사가 빠져 있으므로 **업로드하면 안 된다.** 파일은 비교·복구용으로만
보존한다.

새 EP01은 v5 지침으로 아래 항목을 진행했다.

1. 공식 발굴 자료로 발견 경위·출토품 군·능원 배치·중앙부 미발굴 이유 재조사
2. `발굴확인/측정확인/문헌기록/학술해석/미확인` 증거 지도 작성
3. 진시황릉을 첫 문장에서 밝히고 농부의 발견에서 병마용이 드러나는 순서로 후킹 수정
4. 구어체 담화 표지·강조 부사·종결어미 다양화와 고정 결말 반영
5. 특정 컷 수를 재사용 기준으로 삼지 않고 시간·장소·대상·행동·시각화 변화에서 27장면 파생
6. v5 TTS 27개·라우드니스·강제 정렬 자막 생성 완료

## FLOW 조작 메모 (이번에 확립)

- 프롬프트 입력은 **실제 키보드 타이핑**만 통한다.
  JS `execCommand('insertText')` 는 DOM 에만 들어가고 React 상태에 반영이 안 돼
  "프롬프트를 입력해야 합니다" 로 거부된다.
- 입력창 좌표 `(600, 837)`, 전송 `(888, 870)`. 그리드 타일을 잘못 누르면
  편집기로 들어가므로 y 좌표를 837 아래로 유지할 것.
- 이미지 모드 · Nano Banana 2 · 9:16 · x1 · **크레딧 0**
