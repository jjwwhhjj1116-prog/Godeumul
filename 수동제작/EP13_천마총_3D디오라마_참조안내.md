# EP13 천마총 — 22컷 이미지 입력 안내

대본·TTS와 기존 22컷의 설명 순서는 유지하고 스타일만 변경했다. 생성 완료 파일이 아니라 입력용 프롬프트다. TXT는 빈 줄로 구분한 22개 문단이며 제목이나 이 안내문을 함께 입력하지 않는다.

| 컷 | 실제 첨부할 참조 이름 |
|---|---|
| 01–02, 04–05, 08, 10–13, 16, 18–22 | 천마도 |
| 03 | 천마총금관 |
| 06 | 천마도일 + 천마도 |
| 07, 09 | 말다래사용참조 + 천마도 |
| 14 | 덕흥리천마 |
| 15 | 덕흥리천마 + 천마도 |
| 17 | 천마총내부 + 천마도 |

기존 파일 위치: `산출물/EP13_천마총/FLOW_수동실행_참조패키지/`. 동일 이름의 JPG를 첨부한다. 천마도는 II, 천마도일은 I로 서로 다른 그림이다. 기존 천마도 캐릭터가 등록되어 있어도 다른 참조가 자동으로 생기지 않는다. 이름 인식 여부와 실제 첨부 썸네일을 확인한다.

말다래사용참조는 장착 위치만 참고하고 금색 장식을 복제하지 않는다. 덕흥리 자료와 말다래사용참조의 상업적 이용 조건은 아직 확인이 필요하다. 14–15컷은 권리 확인 전 게시용 확정으로 취급하지 않는다. 천마총내부는 현대 전시 재구성이지 실제 발굴 당시 사진이 아니다.

영상 변환은 이미지 검수 뒤 같은 컷의 시작 이미지로 수행한다. 이 파일은 001→002 식의 서로 다른 장소 간 연속 보간을 승인하지 않는다. 치수·설명선·한글은 TTS에 맞춰 후편집한다.
